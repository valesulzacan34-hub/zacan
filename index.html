Lojas permitidas (nenhuma marcada = todas)

As senhas ficam protegidas no Firebase e não aparecem aqui. Para redefinir a senha de alguém, use o console do Firebase (Authentication → Usuários).

Acesso de cada pessoa às lojas

Gerentes e operadores só veem as lojas marcadas. "Todas" libera todas as lojas, inclusive as que forem criadas depois. Administradores sempre veem tudo.

Fotos e localização dos checklists

Vale para todos os usuários a partir do próximo checklist.

Usuários da versão anterior

O login agora é pelo Firebase. Quem já tinha acesso pode simplesmente entrar com o mesmo usuário e senha de antes: o novo acesso é criado sozinho no primeiro login. Se preferir, crie todos de uma vez aqui. Senhas com menos de 6 caracteres não são aceitas pelo Firebase; essas pessoas precisam de um acesso novo.
